Second Draft

Rewrites what you just typed — softer, shorter, or as a question — using Chrome's built-in on-device model. Nothing leaves your machine.

Chrome Web Store Source on GitHub

Free and open source. Requires Chrome 138+ on desktop, ~22 GB free disk and a supported GPU; the model downloads once.

Why it is different

Every other writing assistant sends what you type to somebody's API. This one cannot: it declares no host permissions, and its Content Security Policy sets connect-src 'none', so Chrome refuses a network request from the extension even if the code attempted one. That makes it usable on the text you would never paste into a web tool — review comments, internal drafts, anything under an NDA.

What it does

  • Softens a blunt comment without weakening the claim
  • Turns a statement into a genuine question
  • Halves the length, keeping the technical detail
  • Fixes only the English, leaving your tone alone
  • Translates to English when the text is not English
  • Runs your own presets, stored on your machine

It never overwrites what you wrote: the draft appears next to the original and goes into the field only when you press Insert. Cmd+Z brings back your words.

Honest limitations

The on-device model is small. It is good at grammar and tone, mediocre at anything needing judgement, and confidently wrong if you ask it about code. The hardware requirements will exclude some laptops entirely — the extension tells you so instead of failing silently.
